# Roadmap: ShiftFlow Bug Fix

## Overview

Two focused phases fix the calculation bugs in `generateSchedule()`. Phase 1 restores correct hours and rest-day counts for all employees. Phase 2 guarantees department coverage in edge cases and eliminates any loop/corruption risk. Both phases operate entirely within `shift-planner.html` — no structural changes, no new features.

## Phases

- [x] **Phase 1: Hours and Rest Calculation** - Fix 40h guarantee and exact restDaysNeeded enforcement
- [x] **Phase 2: Coverage and Safety** - Guarantee minCopertura in edge cases, prevent infinite loops

## Phase Details

### Phase 1: Hours and Rest Calculation
**Goal**: Every employee ends the week with exactly 40h and the correct number of rest days — no exceptions.
**Depends on**: Nothing (first phase)
**Requirements**: ALG-01, ALG-02, EDGE-01
**Success Criteria** (what must be TRUE):
  1. After generating any schedule, every employee row shows exactly 40h in the weekly total
  2. Every employee has exactly `restDaysNeeded` rest days — no extras added, none missing
  3. When an employee has a manual absence (sick/holiday/leave), the remaining scheduled hours still sum to 40h and rest count remains correct
**Plans**: 4 plans

Plans:
- [x] 01-01-PLAN.md — Bug A: restDaysNeeded feasibility check + infeasibility warning (no extra rest days)
- [x] 01-02-PLAN.md — Bug B: Phase 3b Pass 1 hours-aware filter (no straordinario over-hours)
- [x] 01-03-PLAN.md — Bug C: isSoloDept conditional end-lock (no sole-dept 43.5h overshoot)
- [x] 01-04-PLAN.md — Bug D: sync _test_real.js / _test_schedule.js to post-fix browser

### Phase 2: Coverage and Safety
**Goal**: Every department has minCopertura coverage every working day, even with minimal staff, and the algorithm never hangs or produces corrupt output.
**Depends on**: Phase 1
**Requirements**: ALG-03, EDGE-02
**Success Criteria** (what must be TRUE):
  1. Every department meets minCopertura on every non-Sunday day in a generated schedule
  2. With a department where all members are absent on a given day, the algorithm completes (no infinite loop) and marks coverage as unmet rather than hanging
  3. Departments with only 1 or 2 employees still receive valid opener and closer assignments on days when staff is available
**Plans**: 2 plans

Plans:
- [x] 02-01-PLAN.md — EDGE-02 documentation: inline loop-finiteness comments for Phase 1 greedy fallback and Phase 3b Pass 1 (no behavior change)
- [x] 02-02-PLAN.md — ALG-03/EDGE-02 regression tests: 3 new scenarios in _test_schedule.js (single-worker dept, dual-worker dept, all-absent dept)
