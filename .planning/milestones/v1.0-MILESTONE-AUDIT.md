- **Location:** `_test_real.js:227`, `_test_schedule.js:212` vs `shift-planner.html:1818`
- **Issue:** Tests use `hoursLeft + 0.01`; browser uses `hoursLeft + 0.51` (30-minute tolerance on last day)
- **Risk:** Low — currently masked by Phase 3c extension loop compensating both environments identically
- **When it bites:** Only if a future scenario creates a last-day case where Phase 3c cannot compensate, causing silent test/browser divergence
- **Fix:** Align test threshold to `+0.51` to match browser

### Item 2: isOpener term absent from test Phase 2.5
- **Location:** `_test_real.js:204`, `_test_schedule.js:204`
- **Issue:** Browser Phase 2.5 uses `(isOpener || isSoloDept)` for `validSt` lock; tests use only `isSoloDept` because `openerOf`/`closerOf` are not computed in either test
- **Risk:** Low — isSoloDept path (the bugfix target) is correctly tested; opener start-lock for multi-worker depts is verified only end-to-end via hours being correct, not by direct assertion
- **Acknowledged in:** SUMMARY 02-02 (scope boundary)
- **Fix:** Add `openerOf`/`closerOf` computation to test Phase 2.5, or add a direct assertion that the opener in a multi-worker dept always starts at `dayBaseSt`
