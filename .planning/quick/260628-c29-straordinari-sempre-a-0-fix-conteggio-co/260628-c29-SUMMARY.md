## What Changed Per Task

### C29-OT0 — Straordinari sempre a 0
**File:** `shift-planner.html`, Phase 3b Pass 1 (~riga 1957)

**Problema:** `setShift(..., baseEnd, 'Straordinario', ...)` assegnava sempre un turno fino alla chiusura del negozio, ignorando le ore rimanenti al contratto.

**Fix:** Dentro `candidates.slice(0,needed).forEach`:
1. Calcola `remaining = Math.round((emp.ore - calcWeekHours(emp.id)) * 10) / 10`
2. Skip se `remaining < MIN_SHIFT_H` (5.5h) — gap lasciato per coverageIssues
3. Loop di riduzione `endTime` a passi di 30 min finché `shiftHours <= remaining + 0.05`, fermandosi se il passo successivo scenderebbe sotto MIN_SHIFT_H
4. Chiama `setShift(..., null, rep.id)` — nota `null` invece di 'Straordinario'

### C29-COV-SLOT — Conteggio copertura per presenza simultanea
**File:** `shift-planner.html`, nuova funzione top-level + 4 sostituzioni

**Problema:** Headcount giornaliero contava 1 intera + 1 mattina + 1 pomeriggio = 3 invece di 2.

**Aggiunta:** Funzione `repSlotCoverage(rId, dk)` prima di `buildCoverageTable`:
- Un turno copre mattina se `parseHour(s.start) < lunchBreakStart`
- Un turno copre pomeriggio se `parseHour(s.end) > lunchBreakEnd`
- Ritorna `Math.min(morning, afternoon)`

**4 sostituzioni:**
- `getRepWorking` (dentro generateSchedule): arrow semplificata che chiama l'helper
- `coverageIssues` loop (dentro generateSchedule): `const working = repSlotCoverage(rep.id, dk)`
- `buildCoverageTable`: stessa sostituzione
- `updateStats`: stessa sostituzione

### C29-MANUAL-HRS — Input orari manuali liberi nel modal
**File:** `shift-planner.html`, modal HTML + openShiftModal + applyShiftChange

**Aggiunto al markup** (tra #shift-options-grid e #absence-reason-group):
- `<div id="custom-time-group">` con due `<input type="time">` (#custom-start, #custom-end)
- Nota `<small>` che spiega la precedenza e il blocco 🔒

**openShiftModal:** Prefilla i campi SOLO se `existing.manual && existing.start/end` — turni generati aprono il modal con campi vuoti.

**applyShiftChange:** Nuovo ramo in cima:
1. Legge `cStart`, `cEnd`
2. Se entrambi valorizzati: valida `parseHour(cEnd) > parseHour(cStart)` (toast warn se no)
3. Eredita reparto dall'esistente o primo reparto emp
4. Chiama `setShift(..., cStart, cEnd, note, rId, true)` — `manual:true` -> 🔒
5. `return` — salva i rami originali intatti sotto
